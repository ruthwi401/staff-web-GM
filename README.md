# Green Mart V4 — Staff Dashboard

A modern, responsive staff management dashboard demo designed for Green Mart V4. It provides a central interface for staff to manage delivery orders, view delivery locations, monitor inventory, track daily tasks, and check team activity.

## Features

- **Dashboard Overview** — View key operational statistics and daily activity.
- **Order Management** — Search orders, filter order statuses, and update demo orders.
- **Delivery Management** — View delivery assignments, customer details, and sample delivery addresses with map links.
- **Staff Management** — View team members and their work statuses.
- **Inventory Monitoring** — Identify products that may need restocking.
- **Task Management** — View and manage daily staff tasks.
- **Activity Feed** — Review recent actions within the dashboard.
- **Responsive Design** — Designed to work on desktops, tablets, and mobile phones.

## Technology Used

- HTML5
- CSS3
- JavaScript
- Google Maps links for opening sample delivery locations

## How to Run

1. Open this repository on GitHub.
2. Open `index.html`.
3. If you want to test the website locally, download the project and open `index.html` in a web browser.
4. Alternatively, visit the published GitHub Pages website.

## Demo Notice

This project is a **demonstration prototype**. Orders, staff details, delivery addresses, inventory levels, and dashboard statistics may be sample data.

The current demo does not provide a live database, secure staff login, real-time GPS tracking, actual order synchronization, or live delivery notifications. These features require additional backend services and appropriate security.

Do not use real customer information or sensitive business data in this public demo.
